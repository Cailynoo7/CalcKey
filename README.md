# CalcKey

一台紧凑的20键数字键盘兼八位计算器。连接电脑时使用USB HID数字键盘，接5V USB充电器时独立计算。Pico 2、GATERON KS-9三脚红轴、GDM0103/HT1621B LCD；手工矩阵接线，无电池和定制PCB。

主壳89×130×21mm，带独立底盖、两档翻折后脚和20只可打印键帽。正式打印件共28件，透明保护片另行切割。完整设计包包含整机STEP、独立STL、部件清单、接线焊接图、装配指南及v0.2.0固件和源代码。

用户选择跳过打印试配，当前交付为数字设计及编译验证结果；实际插拔力、强度、LCD承托与通电功能未实测。本次没有打印、烧录或供电。

正式制作说明位于Product中的production资料；在Product标签上右键选择Show in Finder可查看。旧OLED固件、旧机械轴与试配件作为历史资料保留，不用于当前整机。
