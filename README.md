# CalcKey

20键USB数字键盘兼八位计算器：接电脑为USB HID键盘，只接5V USB电源时独立计算。主控采用Waveshare RP2350-Plus-16MB无排针版，原生Type-C；保留GATERON KS-9三脚红轴、GDM0103/HT1621B LCD与20键矩阵PCB，不配电池。

主壳89×130×21mm，浅薄荷绿，独立底盖和两档翻折后脚。Type-C为9.44×3.66mm圆角长孔，按原厂插座正面每侧预留0.25mm；接口立台与底盖一体。主控通过两只绝缘压桥和4颗M2×6固定，正式打印件30件。透明保护片另行切割。

矩阵PCB保持73×96×1.6mm双层FR-4，20只1N4148-TAP与4只10kΩ/0805手焊；10根矩阵线加5根LCD线，每根150mm，合计2.25m，采购建议3m。J10只接3V3 OUT，矩阵无GND端子。

固件v0.3.0针对waveshare_rp2350_plus_16mb重新编译，保留双模式、八字符十进制计算和USB状态处理。完整制作包统一采用Type-C版CAD、保形修复主控参考、30个打印件和v0.3.0固件；模型、采购和制作资料通过配套清单绑定版本与文件哈希。

接线、压桥安装与维护见[Type-C主控装配说明](product/type-c-controller-assembly.md)。底盖携主控、LCD、压桥和翻脚向下退出30mm；65mm矩阵自由线段保持。打印公差、主控实际板厚、夹持、USB插拔与整机电气行为仍待实物验收。用户跳过打印试配；没有打印、上电或烧录。
