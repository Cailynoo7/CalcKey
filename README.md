# CalcKey


一台紧凑的20键数字键盘兼八位计算器。连接电脑时使用USB HID数字键盘，接5V USB充电器时独立计算。Pico 2、GATERON KS-9三脚红轴、GDM0103/HT1621B LCD；20键矩阵PCB连接Pico，无电池。

主壳89×130×21mm，带独立底盖、两档翻折后脚和20只可打印键帽。正式打印件共28件，透明保护片另行切割。完整设计包包含整机STEP、独立STL、部件清单、接线焊接图、装配指南及v0.2.0固件和源代码。

用户选择跳过打印试配，当前交付为数字设计及编译验证结果；实际插拔力、强度、LCD承托与通电功能未实测。本次没有打印、烧录或供电。

矩阵板为73×96×1.6mm双层FR-4，全部器件手工焊装；20只1N4148-TAP、4只10kΩ/0805和J1～J10位于底面。10根矩阵引线加5根LCD引线，共15根，默认每根150mm；合计2.25m，建议采购3m。

20个键帽STL包含5键浅圆定位凹点、Enter/=双标识和统一加粗排版，本次键帽形状未变。主壳与底盖保留固定桥版本STL，本次28个打印件全部经几何、安装位置及字节哈希核对后复用；CAD源码已补齐螺钉seat接口声明，完整包收纳修复后的源码、对应STEP与兼容性证据。完整制作ZIP收纳同一几何版本STEP、28件STL、PCB发布与LCD固件记录。矩阵板没有GND端子；J10只接3V3 OUT。旧手焊行列图、九页旧指南、OLED固件及试配件仅作历史资料，不混入正式包。
