# MATRIX A逐项焊接与断电检查

对应PCB发布17123bc08553010640eaa377912e790923ec95a26949b1e102fa73c7f9b2c727及本目录四页焊装图。适用RP2350-Plus-16MB、20枚已确认KS-9三脚红轴、GDM0103/HT1621B。全程不插USB、充电器、调试器或其他外部电源；不烧录。万用表只用电压、电阻、通断和二极管档，不用电流档。

本文是操作指导，所有实物结果尚待操作者提供。原59项空白断电记录继续保留；新版[整机装配与断电检查](../final-assembly/README.md)将这些测点原样纳入154项统一记录，并补充逐键松开/释放、机械回弹及固定桥维护检查。两份表不必重复填，旧的真实记录可引用；资料核对通过不能代替实测。

**如果已经接好主控或LCD，先保留现状并报告进度。下面约10kΩ和二极管方向的判断以矩阵与主控、LCD电气分离为条件；芯片内部路径会改变读数，不为套用判据而反复拆焊焊盘。**

## 0　开工准备——所有板先分开放

准备温控烙铁、电子焊锡和助焊剂、镊子、斜口钳、夹具、吸锡带、放大镜、万用表，以及已选软线、聚酰亚胺绝缘胶带。温度及加热时限按所用焊料和元件工艺要求，不将同一温度套用所有器件。烙铁回支架，避免吸入焊烟，焊接时不让烙铁接触打印件或LCD玻璃。

1. 拔掉所有外部线缆，主控、LCD、矩阵板保持电气分离。若曾通电，先用直流电压档确认待测电源节点没有残余电压，再切电阻/二极管档；不要短接电容放电。
2. 万用表黑笔插COM，红笔插V/Ω口。用电阻档短接表笔，记表线基准值____Ω；分开应显示OL。二极管档可用一只散件二极管确认红笔接A、黑笔接K时正向有压降。
3. 核对板尺寸73×96×1.6mm，SW1～SW20、D1～D20、R1～R4、J1～J10齐全，焊盘无剥离、孔无堵塞和铜屑。
4. 计数：20轴、20只1N4148-TAP/DO-35、4只10kΩ/0805；不把1N4148W/WS贴片二极管或轴向电阻装入本板。
5. 屏幕端朝上，翻到焊接底面：远端第一排D4、D3、D2、D1；近端焊盘左到右J10……J1。此后每次翻板都重新找J1和屏幕端。

本步结束条件：[ ] 外部供电全断；[ ] 仪表接孔正确；[ ] 器件规格和持板方向已核对。

## 1　先焊4只0805上拉电阻——见第4页B

装前分别测4只电阻，标称10kΩ±1%；9.9～10.1kΩ是器件标称公差范围，实际判断还需考虑仪表精度。电阻无极性，不依赖外壳印字辨值。

底面朝你、屏幕端朝上，远端中央的位置是：

| 位置 | 左 | 右 |
| --- | --- | --- |
| 最靠近屏幕的一排 | R4→COL3 | R3→COL2 |
| 下一排 | R2→COL1 | R1→COL0 |

每只先在一个焊盘加少量锡；镊子放正电阻并短暂回流固定一端，冷却后焊另一端，必要时补焊第一端。两端均需润湿，不靠大锡团粘住，不把左右电阻之间的间隙连成桥。若电阻立起或偏移，补助焊剂后修正，不带歪继续焊。

焊完、未接主控/LCD时，所有按键不按下，用电阻档测：

| 表笔一 | 表笔二 | 对应电阻 | 预期 |
| --- | --- | --- | --- |
| J6 | J10 | R1 | 约10kΩ |
| J7 | J10 | R2 | 约10kΩ |
| J8 | J10 | R3 | 约10kΩ |
| J9 | J10 | R4 | 约10kΩ |

列与列之间可通过两个上拉测到约20kΩ；不能要求列间OL。若某列到J10为OL，检查该电阻和两端焊点；若接近表线基准低阻，检查锡桥或错值。异常修复后重测。

本步结束条件：[ ] 4个电阻坐平，无锡桥；[ ] 4项上拉读数已记入检查表。

## 2　焊20只二极管——见第1页底面及第4页A

1. 二极管黑色色环为K，无环端为A。先用散件二极管档核对方向；正向有压降、反向OL。
2. 用钳子支撑引脚再弯折成7.62mm孔距，不拿玻璃管体作杠杆，也不紧贴玻璃端急弯。
3. **器件放在底面；在本图持板方向下黑环一律朝左，对准方形pad1和K标记。**无环A接右侧pad2。先只装D1，保持卧装，不强压管体。
4. 固定D1后翻板焊通孔，重新确认它仍在底面、K与方形焊盘同侧；冷却后红笔接D1的A焊盘、黑笔接K焊盘，有正向压降；交换表笔应OL。读数受仪表测试电流影响，不给整批二极管套一个固定压降值。
5. D1方向和焊点检查通过，再做D2～D20；每次完成一排即检查。二极管引脚从正面剪短，不留尖端顶住后续轴体底部；保留完整焊点，剪下的引脚及时清走。

本步结束条件：[ ] 20个黑环均对K/方形焊盘；[ ] 玻璃管无裂纹；[ ] 正面引脚不顶轴；[ ] 无锡桥或残留金属屑。

PCB已经连接好每键、每行和每列。**不要采用旧手焊版的跨键并线方法，也不要把二极管直接搭焊到轴脚上代替PCB焊盘。**

## 3　安装20轴并焊40个触点——见第1页

1. 先取下键帽。轴从主壳正面卡入面板，每个轴坐平并能回弹。
2. PCB从下方对准每轴的塑料中心柱和两个金属触点，均匀靠合。不以焊锡强拉板就位，不横向挤弯轴脚；插不入先检查方向、引脚或正面二极管剪脚是否干涉。
3. 托住已卡入面板的轴体，确认PCB平整，再从底面焊轴触点。先分散固定四角附近轴的一个触点，复查所有轴与PCB坐平，之后补齐各轴两个触点，共40处。
4. 中心塑料柱孔为NPTH，不焊；不加热热插拔座，因为本设计没有热插拔座。避免烙铁烘烤面板和轴壳，焊点冷却再移动。
5. 检查40处焊点无桥接和明显裂缝，20轴逐个按下、松开，均无卡滞。先不装键帽、不接主控。

本步结束条件：[ ] PCB无翘曲；[ ] 40个金属触点焊完；[ ] 20轴均能回弹；[ ] 中心柱孔未填锡。

## 4　测完整被动矩阵——仍不接主控、LCD

先复测第1步四个10kΩ上拉。然后切二极管档，其他19键始终松开，一次只测一个键：

1. 红笔接表中“列焊点”，黑笔接“行焊点”，松键应OL。
2. 只按目标键，出现正向压降；保持按下并交换表笔，应OL。
3. 放开后回到OL。每键重复按放，读数不应随着轻触板或引线而异常跳变。

| 轴/二极管 | 键 | 红笔：列焊点 | 黑笔：行焊点 |
| --- | --- | --- | --- |
| SW1 / D1 | Num | J6 | J1 |
| SW2 / D2 | ÷ | J7 | J1 |
| SW3 / D3 | × | J8 | J1 |
| SW4 / D4 | Bk | J9 | J1 |
| SW5 / D5 | 7 | J6 | J2 |
| SW6 / D6 | 8 | J7 | J2 |
| SW7 / D7 | 9 | J8 | J2 |
| SW8 / D8 | − | J9 | J2 |
| SW9 / D9 | 4 | J6 | J3 |
| SW10 / D10 | 5 | J7 | J3 |
| SW11 / D11 | 6 | J8 | J3 |
| SW12 / D12 | + | J9 | J3 |
| SW13 / D13 | 1 | J6 | J4 |
| SW14 / D14 | 2 | J7 | J4 |
| SW15 / D15 | 3 | J8 | J4 |
| SW16 / D16 | Enter/= | J9 | J4 |
| SW17 / D17 | Mode | J6 | J5 |
| SW18 / D18 | 0 | J7 | J5 |
| SW19 / D19 | . | J8 | J5 |
| SW20 / D20 | AC | J9 | J5 |

20组松键状态均需检查；原记录表包含每键正向和反向两条，统一整机表的R01～R20另记起始松开与测后释放，均按红列黑行。测量时有疑问先确认隔离条件并定位可疑支路，避免因多个键同时按住或其他外接线改变路径而误判。

| 现象 | 优先查什么 |
| --- | --- |
| 按下仍OL | 持板方向、表笔是否接对J点、轴脚虚焊、二极管开路/装反 |
| 正向OL，反向反而有压降 | 对应二极管K/A装反或表笔接反 |
| 不按也导通 | 轴脚/键内网络桥接、轴体卡住，先检查该键附近 |
| 正反向都接近表线基准低阻 | 锡桥、二极管短路或测到了错误节点 |
| 一整行或一整列异常 | 共同的J点、行/列网络及该区域焊点 |
| 只有轻压PCB才通 | 虚焊、脚未穿过PCB或受力接触，不合盖掩盖问题 |

本步结束条件：[ ] 4列约10kΩ；[ ] 20键松/按/反向/释放均已检查；[ ] 异常均处理并复测。未满足前不接主控或LCD。

## 5　焊J1～J10的10根软线——见第2页

每根总长默认150mm，先在两端标J号；其中上下壳夹持区之间保留至少65mm自由段，不能先按直线距离剪短。只剥覆盖铜垫所需的一小段，线股不得散开。先给线端与铜垫少量预上锡，线端平铺向板内焊接，不让裸线越过铜垫，不把电烙铁当支点压住铜垫。冷却后按新版桥位包夹线皮，跨壳自由段不粘死；不拉扯焊点检查牢固度。

先焊PCB端，主控端暂不焊。用通断/电阻档测每根自由线端到原J铜垫，应接近表线基准；检查是否有相邻J垫桥接。之后才焊主控端，每焊一根核对一根：

| 矩阵点 | 信号 | 主控信号 | 主控物理脚 |
| --- | --- | --- | --- |
| J1 | ROW0 | GP2 | 4 |
| J2 | ROW1 | GP3 | 5 |
| J3 | ROW2 | GP4 | 6 |
| J4 | ROW3 | GP5 | 7 |
| J5 | ROW4 | GP6 | 9 |
| J6 | COL0 | GP7 | 10 |
| J7 | COL1 | GP8 | 11 |
| J8 | COL2 | GP9 | 12 |
| J9 | COL3 | GP10 | 14 |
| J10 | V3V3 | 3V3 OUT | 36 |

主控元件面朝你、USB朝上时，物理1左上、40右上；物理脚编号不是GP编号。翻到背面焊接时左右相反；装机USB朝右，不能按装机的左上角重新数针脚。

**矩阵没有GND端子。J1～J5是扫描行，不能接地；J10不得接VBUS、VSYS、3V3_EN或5V。**

本步结束条件：[ ] 10根线两端J号一致；[ ] 端到端读数稳定；[ ] 无散股、焊盘桥接和裸线越界。

## 6　焊LCD五根线并绝缘——见第3页

LCD沿厂家图纸显示上边持板：显示面左侧自上而下P1～P6；保持上边不变翻到背面，变成右侧自上而下P1～P6。先找P1丝印再认信号；不要把LCD的P1与主控物理脚1混为一谈。

| LCD端子 | 信号 | 主控信号 | 主控物理脚 |
| --- | --- | --- | --- |
| P1 | /CS | GP11 | 15 |
| P2 | /WR | GP1 | 2 |
| P3 | DATA | GP0 | 1 |
| P4 | VSS | GND | 38 |
| P5 | VDD | 3V3 OUT | 36 |

1. LCD五线每根约150mm，先标号，低位直焊，不装直立排针。板背焊点与首段导线突出≤1.5mm，向板内平铺，不用焊锡、胶或工具压玻璃。
2. J10与LCD P5接到同一3V3节点——主控物理36。两根线固定好线皮，不让它们把针脚35、37桥接，不把大锡团堆到相邻焊盘。
3. LCD P6 /INT、P7 BL+、P8 BL-、P9 Ctrl不接外部导线，有裸露引出部分则分别绝缘，不把四个端子互相短接。不添加背光接线。
4. 冷却后逐根测LCD端子到对应主控脚的端到端导通，并目视相邻焊点无桥接。NC表示不接外部线，不意味着模块内部任何两端子必须测为OL。

本步结束条件：[ ] 五线一一对应；[ ] LCD用3.3V；[ ] P6～P9独立绝缘；[ ] 无高起焊点或压玻璃。

## 7　整机断电复核与暂合盖

1. **仍不插USB。**复核15根导线的端到端通断和标签，确认LCD P4到主控物理38、LCD P5与J10到物理36。
2. 目视检查主控、LCD及矩阵的相邻焊点，无锡桥和裸线散股。特别检查主控物理35/36/37/38一带。已连接芯片后，不以所有相邻信号脚必须OL作为合格条件。
3. 用电阻档测3V3 OUT—GND，观察稳定值和变化趋势并记录。模块电容和保护路径可能影响读数；不要求固定某个阻值或OL。若持续接近表线基准的低阻，先查桥接并隔离支路定位；不要带疑问上电。一次没蜂鸣不能证明整机通过。
4. 主壳前左桥固定J1～J5、前右桥固定J6～J10，底盖前中桥收拢10线，后中桥固定LCD五线；左侧辅助桥只整理自然可达余段。矩阵每根夹持区之间保留≥65mm自由段，左右各5线松放S形；LCD只固定到底盖。包带搭接≥15mm，桥顶含胶带束高≤1.5mm；裸铜仍独立绝缘，不靠胶带包桥替代热缩。余线区和位置按新版整机手册，不用旧单块储线预算。
5. 托住底盖缓慢合拢，确认没有夹线、PCB弯曲或顶住LCD，再拧4颗M3。断电卸螺钉、手托底盖沿局部负z下放30mm，观察矩阵线自然展开、焊点不受拉，LCD五线随底盖移动；完全分离仍要断开焊线，不以线拉住底盖。重合盖后复查键帽回弹与供电节点趋势。
6. 不插电逐个按20键，检查回弹；装键帽后再检查按下和释放。若合盖后才卡键或读数变化，打开查干涉，不靠拧紧盖板压平PCB。
7. 保存记录，停在“焊装与断电检查已记录、功能待上电验收”。本指南不包含接电、烧录、显示/USB功能或多键防冲实测，这些尚未验证。

本步结束条件：[ ] 15线导通记录完整；[ ] 供电节点没有可疑持续低阻；[ ] 线材、玻璃与机构无干涉；[ ] 所有疑问已记录；[ ] USB仍未连接。

## 报读数时用这个格式

不要只说“全响了”或“都正常”，提供具体节点、档位和状态，便于区分短路、二极管方向和虚焊：

```text
当前进度：未焊 / R+D完成 / 轴完成 / 已接主控 / 已接LCD
外部电源：全部断开
仪表：型号（若知道）；红笔V/Ω、黑笔COM；表线基准____Ω
矩阵测量时主控/LCD：未连接 / 已连接
上拉：J6-J10____kΩ，J7-J10____kΩ，J8-J10____kΩ，J9-J10____kΩ
异常键：SW__ / D__
表笔：红J__、黑J__；二极管档
松开____；按下____；按住换表笔____；释放____
目视：黑环对K / 有疑问；桥接、翘板或卡键现象____
```
