> 外壳更新：本次主壳与底盖已增加五处线束固定桥，装配检查及新STEP单独交付。此处原28件STL和完整制作ZIP仍是79bb392版，其中主壳与底盖尚无固定桥，需更新后用于新版制作。线长、GPIO、PCB与LCD固件不变；整理方式见线束固定说明。

## 整机装配顺序

1. 按文件制作28件，清理孔内残料。装配时观察打印缺陷与配合；用户跳过试配不代表裂件可以强压装机。保护片另切割，材料与尺寸按清单。
2. 左右翻脚装入底盖轴耳，穿销轴。端帽内径2.6、深1.2，轴入帽1mm；只在轴端与帽内孔点少量环氧胶，胶不得流入轴耳或脚的转动面。两脚都到同档限位后才落桌。
3. 按PCB版逐项手册先焊4个0805上拉，再焊20个底面卧装二极管；屏幕端朝上看底面时，黑环K朝左，接方形pad1。轴从顶侧扣入面板后套入PCB，确认坐平再焊40个金属触点，中心塑料柱孔不焊。矩阵由PCB铜线连接，不跨键并线，不把二极管搭焊到轴脚。独立矩阵断电测量通过后再接Pico。
4. Pico以两颗M2×4固定到底盖；原生Micro-B向右。LCD P1 /CS→GP11、P2 /WR→GP1、P3 DATA→GP0、P4 VSS→GND、P5 VDD→3V3；P6～P9分别绝缘不接，初版不接背光。板背焊线朝内、突出不大于1.5mm，不装直立排针。
5. LCD PCB以四片0.15mm绝缘胶片粘到底盖边缘托架，座面z7.25、PCB底z7.4；只接PCB边缘，不压玻璃。主壳内粘胶框与保护片。此LCD无精确STEP，承托带依据厂家图及空间预算，实际铜箔/器件不能被托架顶住。
6. J1～J10的10根矩阵引线及LCD五线保留维护余量。已绝缘余线在底盖左侧平铺：局部X=-36～-16、Y=-40～10、Z=3～7.5mm为检查过的20×50×4.5mm预算；用聚酰亚胺胶带固定绝缘层，避免焊点承力。不要堆高线团、跨螺柱或堵USB插头，裸铜仍靠热缩绝缘。
7. 按PCB版逐项操作手册做实际通断/极性检查，使用59项记录和20键测点表；表格留给操作者填写，本交付没有代填通过。主壳与底盖对齐定位唇，底部4颗M3×8轻拧，贴前脚垫；安装20帽，检查全行程和回弹。名义帽底间隙松开5.5、压到底1.5mm，仅作模型参考。
8. 维护先拔USB、托住底盖，卸4颗M3后沿壳体法向下放30mm，不拉扯线束。完全分离仍需断开焊线。先不烧录、不开始供电功能验收。

## 软件与操作

电脑USB枚举完成默认数字键盘；只接5V充电器默认计算器。Mode在电脑连接时可切本地计算，切换释放HID键；AC只清本地计算器，不发电脑快捷键。USB挂起保留模式，不用超时猜测主机拔出。

计算器采用逐步计算，支持加减乘除、小数、负结果、退格、重复等号、除零及溢出Err；最多8个实际字符，负号占一位，小数点独立。键盘模式屏幕PC 1/PC 0显示主机NumLock状态。完整算术规则见固件说明；旧v0.1.0 OLED固件不用于此屏。

## 验证范围

20帽有效且单实体，静止对20轴无穿插；4mm行程对外壳最近1.5mm，步长0.25mm、17姿态、网格0.02mm。轴体侧向定位筋的20处名义干涉已明示，每轴0.15936mm³、深0.1374mm；不能把它视为保持力实测。余线预算对底盖、主壳、Pico、螺钉及保护片无穿插。

厂家轴体STEP将活动轴芯与壳体融合，运动检查仅验证外部避让，内部机构未独立验证。LCD用厂家机械图及保守包络，没有伪造精确模型。打印收缩、插拔力、卡扣弹性、胶黏保持、翻脚承载、实际LCD承托和烧录后的电气/USB功能均无实测结果。用户跳过打印试配的选择已记录，产品功能与结构验收目标保持。

## 版本与文件选择

- 整机：当前CAD导出记录和模型绑定记录共同指定STEP，不按旧目录名或旧ZIP猜版本。
- PCB：当前release-index指定的matrix发布；Gerber和钻孔直接来自发布包，不重新拼凑或手改。
- 固件：只使用GDM0103 LCD v0.2.0，二进制和源码哈希与编译验证记录一致；保持flashed=false和hardware_tested=false。旧v0.1.0是OLED版本，不适用。
- 焊装：使用matrix-assembly-diagrams四页图与guided-soldering逐项手册；旧diagrams/assembly目录仅作历史。
- 采购：板用1N4148-TAP和0805电阻；装机1块裸板，建议采购5块备板，轴22枚、二极管30只、电阻20只和软线3m的备料默认值见采购表，不等于组装5台。

## 文件取得与复现

在Replicator中右键Product标签→Show in Finder可查看本正式包；当前STEP也可在enclosure设计标签→Export→One STEP或STEP per part (.zip)→选择零件→Export…。单独保护片可选screen_lens后Export STEP…。

generate_models.py只读取交付STEP，用--keycaps-only重新转换20帽并严格核对复用的8件；verify_mesh_features.py直接读取STL检查5键凹点深度与Enter/=两行槽底。sync_delivery_records.py保留旧装配检查revision并验证未变物体，不将旧检查改写成新实测。build_delivery.py核对当前CAD/PCB发布、28项BOM、采购、PCB版图纸与固件哈希并生成统一ZIP，不编译建模、不写设备或启动打印。固件重新构建由design/firmware/build.py执行，依赖在锁定记录中。完整包中的来源与哈希见model-manifest.json、design-verification.json及package-manifest.json。

当前文档整理不触发打印、焊装实测、上电、烧录或下单；实物检查继续待测。


## 键帽网格与复核

20帽采用Arial Bold凹刻：数字/运算符4.8mm、文字3.3mm，深0.35mm；字号不是实际字形高度。5键直径2mm、深0.35mm球面凹点，Enter与=上下双行。全体维持18.2×18.2×7mm外廓及原十字插座。转换后对真实STL表面测得凹点深度并核对两行槽底；20帽均为闭合网格，单位mm、100%比例、顶面向下、Z=0。

球面极点可能导出重复顶点的零面积三角片；转换器仅移除严格重复顶点的零面积片，再检查全部网格边均由两面共享，不移动顶点、不补洞、不改变有效表面。8个非键帽网格经导出形状与放置完全一致后复用。

使用带build123d 0.10.0的CAD Python执行网格转换；其余核验、同步和打包脚本使用Python标准库。以下命令只生成/核对文件：

```sh
python product/production/generate_models.py manufacturing/enclosure/releases/export-b41154b115ba9c61a396ed39b36889a5/receipt.json --keycaps-only
python3 product/production/verify_mesh_features.py
python3 product/production/sync_delivery_records.py
python3 product/production/build_delivery.py
python3 product/production/build_delivery.py --check-only
```

完整包使用独立制板ZIP与PCB不可变发布逐文件核对，不需要重新布线或创建订单。--check-only核对已交付ZIP的目录、逐文件字节、CRC及CAD/PCB/固件和采购绑定，不依赖缓存，不写设备。新版STL已包含定位凹点和双标识，不与旧字形网格混用。
