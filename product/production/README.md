# CalcKey 正式制作交付

本版直接交付整机设计，按用户要求跳过打印试配，先不烧录。主方案为Pico 2、20个GATERON KS-9三脚红轴、20只自制打印键帽、GDM0103/HT1621B八位LCD；USB接电脑作数字键盘，接5V充电器作本机计算器。无电池、无定制PCB。

## 交付内容

- 当前整机STEP及其导出记录，包含20轴和20帽的装配参考。
- 28个独立STL、网格来源及校验记录、打印件清单。STL均由该次STEP转换，单位mm、100%比例，已按各件默认打印方向落到Z=0；没有切片、排盘、G-code或打印机任务。
- 正式部件清单、四页A3接线图、九页A4断电装配/焊接指南及空白电气记录。
- 当前LCD固件v0.2.0：UF2/ELF/BIN、源代码、测试、依赖锁及构建记录。文件已编译验证，本次不执行任何设备写入。
- 六孔板和P0/P5/P10为可选历史试配资料，未列入正式28件、采购清单或本次完成设计的前置条件。

## 另购与切割件

以正式部件清单为准：Pico 2×1；GDM0103/HT1621B **3.3V、6点钟视角**×1；KS-9H10B045NN-X14三脚红轴×20（用户已确认与所用-FB标识模型一致）；轴向1N4148×20；10kΩ±1%轴向电阻×4；M3×8圆头螺钉×4、M2×4圆柱头螺钉×2。

透明亚克力保护片单独切割：67.6×19.6×1mm、四角R1，不打印；当前STEP中的screen_lens是其准确形状。安装用0.15mm胶框，外67.6×19.6、内64×16mm。LCD四处PCB边缘各用2×4×0.15mm绝缘胶片；前端两个D12×2mm硅胶垫；PETG轴帽用少量双组份环氧胶固定。另有USB-A至Micro-B数据线、5V/1A USB-A充电器、26AWG柔性线、热缩管和10mm宽聚酰亚胺固定胶带。

## 整机装配顺序

1. 按文件制作28件，清理孔内残料。装配时观察打印缺陷与配合；用户跳过试配不代表裂件可以强压装机。保护片另切割，材料与尺寸按清单。
2. 左右翻脚装入底盖轴耳，穿销轴。端帽内径2.6、深1.2，轴入帽1mm；只在轴端与帽内孔点少量环氧胶，胶不得流入轴耳或脚的转动面。两脚都到同档限位后才落桌。
3. 按既有断电指南分段焊接：每键列→开关→1N4148无环A→黑环K→行；行不是GND。用热缩分别包住裸焊点，交叉的行列保持绝缘，装上4个10k列上拉。机械轴由顶侧扣入主壳，不能用键帽代替压轴工具。
4. Pico以两颗M2×4固定到底盖；原生Micro-B向右。LCD P1 /CS→GP11、P2 /WR→GP1、P3 DATA→GP0、P4 VSS→GND、P5 VDD→3V3；P6～P9分别绝缘不接，初版不接背光。板背焊线朝内、突出不大于1.5mm，不装直立排针。
5. LCD PCB以四片0.15mm绝缘胶片粘到底盖边缘托架，座面z7.25、PCB底z7.4；只接PCB边缘，不压玻璃。主壳内粘胶框与保护片。此LCD无精确STEP，承托带依据厂家图及空间预算，实际铜箔/器件不能被托架顶住。
6. 九条矩阵主线及LCD五线保留维护余量。已绝缘余线在底盖左侧平铺：局部X=-36～-16、Y=-40～10、Z=3～7.5mm为检查过的20×50×4.5mm预算；用聚酰亚胺胶带固定绝缘层，避免焊点承力。不要堆高线团、跨螺柱或堵USB插头，裸铜仍靠热缩绝缘。
7. 按九页断电指南做实际通断/极性检查；表格留给操作者填写，本交付没有代填通过。主壳与底盖对齐定位唇，底部4颗M3×8轻拧，贴前脚垫；安装20帽，检查全行程和回弹。名义帽底间隙松开5.5、压到底1.5mm，仅作模型参考。
8. 维护先拔USB、托住底盖，卸4颗M3后沿壳体法向下放30mm，不拉扯线束。完全分离仍需断开焊线。先不烧录、不开始供电功能验收。

## 软件与操作

电脑USB枚举完成默认数字键盘；只接5V充电器默认计算器。Mode在电脑连接时可切本地计算，切换释放HID键；AC只清本地计算器，不发电脑快捷键。USB挂起保留模式，不用超时猜测主机拔出。

计算器采用逐步计算，支持加减乘除、小数、负结果、退格、重复等号、除零及溢出Err；最多8个实际字符，负号占一位，小数点独立。键盘模式屏幕PC 1/PC 0显示主机NumLock状态。完整算术规则见固件说明；旧v0.1.0 OLED固件不用于此屏。

## 验证范围

20帽有效且单实体，静止对20轴无穿插；4mm行程对外壳最近1.5mm，步长0.25mm、17姿态、网格0.02mm。轴体侧向定位筋的20处名义干涉已明示，每轴0.15936mm³、深0.1374mm；不能把它视为保持力实测。余线预算对底盖、主壳、Pico、螺钉及保护片无穿插。

厂家轴体STEP将活动轴芯与壳体融合，运动检查仅验证外部避让，内部机构未独立验证。LCD用厂家机械图及保守包络，没有伪造精确模型。打印收缩、插拔力、卡扣弹性、胶黏保持、翻脚承载、实际LCD承托和烧录后的电气/USB功能均无实测结果。用户跳过打印试配的选择已记录，产品功能与结构验收目标保持。
