# CalcKey Type-C完整制作资料

主控为Waveshare RP2350-Plus-16MB无排针版、SKU 29761；GDM0103/HT1621B为3.3V、6点钟视角。保留73×96×1.6mm矩阵PCB和20个GATERON KS-9三脚红轴。固件为v0.3.0、目标waveshare_rp2350_plus_16mb。不配电池，板载电池座不接。

## 配套版本

整机CAD几何版本18faaed，当前STEP、导出记录、源码和哈希由model-manifest.json的current_binding与package-manifest.json共同指定。主控参考使用保形修复版本，原厂原始文件与修复证据一并保留。

完整制作ZIP包含当前整机STEP、CAD源码及活动资产、30个独立STL、31项BOM、PCB制造发布与打样参数、采购表、Type-C四页焊装图、装配说明及154项空白检查表、v0.3.0固件二进制/源码/编译记录。旧Pico 2/v0.2.0、手焊矩阵、试配片和其他主控候选不作为当前制作文件。

30件STL中，主壳和底盖重新转换，新增两只主控压桥；其余26件保留原网格，逐项核对形状、安装位置、字节哈希和闭合性。历史记录只用于这些网格的来源追踪，不代表新做实物测量。

## 材料与打印件

- PLA：主壳、底盖、压桥A/B，共4件。默认0.4mm喷嘴、0.15mm层高、4壁；壳体20%填充，压桥100%。
- PETG：翻脚2、销轴2、短端帽2，共6件；默认0.4mm喷嘴、0.15mm层高、100%填充。
- PETG键帽20件：0.2mm喷嘴、0.10mm层高；保留5键浅定位凹点及Enter/=双行字槽。

STL均为mm、100%比例、单件已定向并落到Z=0，不能再套整机4°装配倾角。详细支撑及清理建议见打印准备说明和30行设置表。不能打印主控、矩阵PCB、轴体、螺钉或透明保护片。保护片为67.6×19.6×1mm亚克力，单独切割。

## 紧固与绝缘

合盖用4颗ISO7380-1 M3×8；主控两只压桥用4颗ISO4762 M2×6。四个底盖板边座、四个压桥接触面各贴6×1.4×0.15mm绝缘胶片，共8片；螺钉不穿主控板，不压芯片，不靠强拧弯板补偿。原厂STEP的0.41148mm板厚仅是模型表示，实际板厚、焊点和夹持必须核对。

LCD用四片2×4×0.15mm绝缘胶片承托PCB边缘；保护片沿用0.15mm周边胶框。前脚垫D12×2mm两只。短端帽只胶接销轴端，胶不能进入转动孔。

## 接线和装配顺序

1. 保持USB、充电器及调试器断开。先按矩阵PCB焊装图安装4只10kΩ/0805电阻、20只1N4148-TAP二极管，再对齐面板中的轴体及PCB，焊40个金属触点；塑料柱孔不焊。逐段记录断电测量。
2. 10根矩阵线和5根LCD线两端标号，逐根低位直焊到主控，不安装排针或插座。每根默认150mm，合计2.25m，建议备3m。J10与LCD P5接3V3 OUT/物理36，LCD P4接GND/38；矩阵没有GND端子。LCD P6～P9各自绝缘。
3. 先贴绝缘垫并焊好主控线，再均匀轻拧两只压桥。Type-C向机身右侧。LCD五线全部固定到底盖；上壳与底盖间的10根矩阵线各保留至少65mm未粘死自由段。
4. 沿五处一体桥用10mm宽、总厚≤0.1mm聚酰亚胺胶带固定线皮。右矩阵余线区为(26,-39,4.55)、20×16.8×3mm；压桥之间只穿三根电源线，其他信号从主控前缘分散出线，不沿用旧宽扇出预算。完整坐标与维护方法见Type-C主控装配及线束说明。
5. 自然合缝后装4颗M3×8。接口立台随底盖进入主壳维护缺口；外露孔9.44×3.66mm，每边留0.25mm间隙。仅用另一端悬空的USB-C线做断电机械试插，不能接电脑或充电器。
6. 维护先拔USB、卸4颗M3并手托底盖，下放30mm；主控、LCD、压桥及翻脚随底盖移动，不横撬Type-C口、不靠线束承重。完全分离仍需脱焊矩阵线；可插拔接头仅是评估，未加入设计。

整机手册和154项空白表给出逐项测点、判据及记录位置。59项电气测点包含在统一表中；所有实测及结果仍为待测，不预填合格。

## 软件与验证边界

v0.3.0编译记录包含93项核心、47270项LCD检查、2500组算术及3023组显示对照。封装过程只验证源码与二进制哈希，不重新编译、不烧录。电脑枚举后默认键盘，仅接USB电源默认计算器，Mode切换释放HID按键。

CAD、STEP和STL检查不代替实物板厚、夹持强度、打印公差、轴体卡扣、胶带保持、LCD承托和USB插拔验收。LCD采用厂家尺寸包络；轴体内部运动没有独立建模。没有打印、上电或烧录。

## 取得文件和复核

右键Product标签 → Show in Finder查看完整制作ZIP及SHA256文件。单独保存STEP：enclosure → Export → One STEP或STEP per part (.zip) → 勾选对象 → Export…。当前正式文件以清单指定版本为准。

标准库封装复核：python3 product/production/build_delivery.py --check-only。脚本检查当前CAD、30网格、PCB发布及制造ZIP、采购覆盖、15线、空白记录、固件和整包逐文件哈希/CRC，不接触硬件。generate_models.py只从已发布STEP转换，绝不重放CAD源码；本版用--typec-only转换四件并验证复用26件。
