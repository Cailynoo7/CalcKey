# 矩阵PCB与LCD线束固定、合盖及维护

本说明对应本次带一体穿带桥的主壳与底盖。RP2350-Plus-16MB、MATRIX A PCB、20个KS-9、LCD与GPIO均沿用现版；不添加排针、插座、扎带或独立卡扣。以下为制作默认尺寸与装配要求，不是已做的实物拉力或柔性运动测试。本次不打印、不上电、不烧录。

## 固定结构与材料

主壳前内壁两座桥分别固定J1～J5、J6～J10的绝缘线；底盖前中桥收拢矩阵线，后中桥固定LCD五线，左侧桥供可达的剩余线段辅助整理。LCD线不绑到主壳或矩阵板，否则开盖会拉扯屏幕。

五座桥均为壳体一体结构：外廓16×14.6×3.6mm，穿带口10.6×2mm，桥顶最薄1.6mm、侧腿2mm、上沿与孔角R0.4。沿用10mm宽、总厚≤0.1mm聚酰亚胺胶带，默认裁5条10×65mm；从桥下横穿，再包住桥顶的绝缘线皮，带尾互搭至少15mm。左侧辅助桥按实际可达余线使用，不强迫线束绕远。胶带不得遮住元件、覆盖裸焊点来代替热缩绝缘，也不得拉紧到线皮凹陷。

局部坐标以未倾斜底盖底面z=0为基准，远端LCD方向为+y：

| 固定桥 | 中心x/y（mm） | 桥根z／桥顶z（mm） | 线束 |
| --- | --- | --- | --- |
| 主壳前左 | -17 / -55.7 | 5.2 / 8.8 | J1～J5，5线单层 |
| 主壳前右 | 17 / -55.7 | 5.2 / 8.8 | J6～J10，5线单层 |
| 底盖前中 | 0 / -29 | 2.4 / 6.0 | 10根矩阵线单层并排 |
| 底盖后中 | 0 / 23 | 2.4 / 6.0 | LCD P1～P5，5线单层 |
| 底盖左侧 | -26 / 2 | 2.4 / 6.0 | 可达余段，辅助整理 |

26AWG多股柔性线绝缘外径≤1.3mm，桥顶5线宽≤6.5mm、10线宽≤13mm。胶带外包后按1.5mm总高度预算。默认每根总长150mm，10根矩阵加5根LCD合计2.25m，采购3m。**150mm是整根线长，不是焊好后额外再留150mm。**先保留全长，干排线后才处理末端，不能先剪成两固定点之间的直线长度。

## 走线与维护余量

1. J1～J10位于PCB底面、局部y=-60.5mm。焊点、引脚先分别绝缘，首段朝PCB内侧弯，再分别到前左／前右桥；不要向前夹入底盖定位唇。桥上只固定线皮，焊点到夹持区保留柔性过渡，避免在刚性焊锡与软线交界折出死角。
2. 每组5线从上壳固定桥到下壳前中桥，**每根保留至少65mm未粘死的自由段**。闭合状态分别在前左／前右整理成松弛S形，单根弯曲内半径默认≥5mm；两固定点之间的线不能粘到底板，开盖时需要释放折返。
3. 左矩阵折返区为20×21.4×3mm、中心(-26,-36.7,4.55)；右区改为20×16.8×3mm、中心(26,-39,4.55)，不得超出已检查区域堆高；这不是整根线都必须塞入的盒子。两组各5根平铺，禁止把10根扭成圆束或叠在合盖柱旁。
4. 从前中桥到主控逐线分散出线。两压桥间仅供3根电源引线通过，预算5×23×1.5mm、中心(18.9,-9.5,10.05)；信号沿前缘分散，预算45×1.5×1.5mm、中心(17,-21.7,7.1)。不能把它们当成15线全束导管，焊端另降到真实焊盘。避开Type-C壳与插头，导线不得压到主控元件或矩阵焊脚。
5. LCD P1～P5保留150mm软线，板背首段突出≤1.5mm，朝板内弯并从显示区前方引向底盖后中桥；避开两侧托架和前挡边。LCD与主控都在底盖，开盖时彼此没有30mm相对位移。P6～P9分别绝缘、不连接。余线可在左侧20×18×3mm区域、中心(-26,-15.5,4.55)松放；只在不拉紧五线的前提下用左侧辅助桥整理。
6. 65mm自由段对应两桥中心闭合约31.77mm、底盖下放30mm后约45.51mm直线距离，展开后仍有约19.49mm长度差供弯曲。这只是几何余量估算，不能替代真实柔性线的弯曲、摩擦与保持力检查。其余长度用于板端过渡、主控扇出与焊端；干装若不能保留65mm自由段，应延长该根软线，不能牺牲开盖余量。

## 合盖与后续维护

断开USB后整理线束，手托底盖，缓慢合入定位唇。先观察四周合缝，若有回弹或缝隙，重新整理线束，不以螺钉强拉合壳。确认合盖柱周围、定位唇、USB口、LCD边缘托架、机械轴焊脚及翻脚机构内没有线或胶带尾。

后续实物装配时，在断电状态卸四颗M3，手托底盖沿局部负z下放30mm，确认矩阵S形线自然展开、两端焊点不受拉、LCD五线随底盖一起移动。不要用线束悬挂底盖；完全分离仍须断开焊线。需要重排线时剥掉或小心剪开胶带，换新条，不拉拽导线来脱离胶带。胶黏力、打印收缩、实际弯曲半径及反复开盖寿命均未实测。

## 制作方向与版本

底盖托架朝上，新增2mm高穿带孔为10.6mm短跨桥接，孔内不填难以清理的支撑；清除垂丝后再穿带。主壳仍键面朝下，新前内壁桥向腔内伸出约14.2mm，需在伸出桥的下方设置可移除局部支撑；不能把支撑塞进穿带孔、轴孔或螺纹孔。打印与支撑是后续工艺，此次不切片、不打印。

Type-C版更新主壳top、底盖base并增加两只独立主控压桥，外廓89×130×21mm、20键、LCD座面和后脚机构保持。当前制作交付为固定桥STEP、重新转换的主壳与底盖STL，以及经形状/安装位置/哈希核对复用的其余26件网格，共30件。完整包纳入新版整机装配手册与154项空白记录，按当前模型清单和逐文件哈希配套使用；历史网格与ZIP不标识当前交付。
