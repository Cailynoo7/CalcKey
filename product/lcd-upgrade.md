# GDM0103 LCD替换说明（2026-11-05）

主选：Good Display / 大连佳显 GDM0103，HT1621B，3.3V、6点钟视角；不是GDC裸玻璃，也不是常见的六位HT1621模组。8位七段数字及独立小数点。半透正显，初版背光不接；日后背光需单独核对电流/串联电阻，不能直连GPIO。

| LCD端子 | Pico信号 | Pico物理针 |
| --- | --- | --- |
| P1 /CS | GP11 | 15 |
| P2 /WR | GP1 | 2 |
| P3 DATA | GP0 | 1 |
| P4 VSS | GND | 38 |
| P5 VDD | 3V3(OUT) | 36 |
| P6 /INT | 分别绝缘，不接 | — |
| P7 BL+、P8 BL-、P9 Ctrl | 分别绝缘，不接 | — |

三线写入采用GPIO位操作，不是I²C；原4×5矩阵GP2–GP10及列上拉不变。按手册P1标记核对方向，不靠线色。低位直焊P1–P5，板背焊点/软线首段突出≤1.5mm，所有焊点绝缘；每根总长默认150mm，LCD线只固定到底盖并随Pico一起移动。矩阵跨上下壳固定点之间另需在这150mm总长中保留至少65mm未粘死自由段，具体按新版固定桥整机手册。选购不带直立排针的版本或拆除排针后装配。

厂家整板尺寸78×26×10mm最大；PCB底面z7.4、板厚1.6mm（手册图）。为不依赖上/下表面的精确零点，CAD保守地在PCB底面以上预留10mm至z17.4，另在中央74×22mm范围向板背预留2.8mm至z4.6；两侧各2mm承托带必须确认无元件/裸铜。保护片底z18.2，最小高度预算0.8mm。四个托架座面z7.25，x±38.2、y41/57；各贴0.15mm绝缘丙烯酸胶片，板背粘接区域先确认无元件、焊盘或裸铜。左右挡边内侧x±39.3，前限位y35.7，均有约0.3mm装配间隙；不用未完整标注的安装孔。元件背面未知区用整个10mm厚包络保守避让，不宣称有精确整板STEP。

窗口64×16mm、中心(0,49)；保护片67.6×19.6×1mm，R1；槽68×20mm，胶框内64×16。订购时锁定78×26板框，不接受同名六位或不同转接板版本。装配前核对板框、厚度、可视区中心及P1方向；前方6点钟视角朝使用者。先干装、确认不挤玻璃，再贴PCB边缘胶，去胶时支撑PCB，勿撬玻璃。

新LCD固件v0.2.0已适配：HT1621B初始化/写RAM、手册第8/12页段码及小数点映射、8字符有符号格式、溢出/除零Err、PC/CALC短提示，桌面测试及Pico 2交叉编译已完成。第8位无末尾点，输入末尾小数点时左移一格，满8字符整数不再接受小数点；每步按可显示位数舍入，后续运算使用显示值。按用户要求先不烧录。旧v0.1.0 UF2为OLED版本，不适用。制作接线使用矩阵PCB版四页A3图和逐项操作手册；新版整机装配手册及154项空白检查表完整纳入原59项电气测点，补充固定桥、线束和开盖检查。矩阵板J1～J10的10根软线和LCD五线共15根，矩阵不再采用逐键飞线；4个列上拉为0805。早期LCD-B手焊行列图与九页手册仅作历史资料。本次未烧录、未通电或实物验收。
