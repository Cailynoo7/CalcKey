## 焊装与断电检查入口

按矩阵设计的assembly说明操作：先焊背面R/D，再将20轴扣入面板并对齐PCB、焊40个轴触点，然后接J1～J10和LCD引线。J1～J5→GP2～GP6，J6～J9→GP7～GP10，J10→3V3；矩阵板无GND端子，J10不接5V。先完成逐键二极管档、上拉电阻和线束通断检查，再合盖；本清单不执行上电或烧录。

同目录附打样参数JSON/CSV、采购CSV及工具耗材CSV，所有数量均有装机/采购区分。整机BOM、当前PCB源文件与发布制造文件不因本次采购准备而改变。
