# CalcKey v0.2.0 烧录与实机验收表

本表只记录真实设备结果。屏幕配置为GDM0103 / HT1621B，旧OLED v0.1.0包不适用。编译及桌面测试已经通过；实机项目尚未执行，全部保持待测。固件对应Pico 2 / RP2350与GDM0103八位LCD；交付件的大小和SHA256以v0.2.0验证记录为准。本表供后续验收准备，用户要求先不烧录，本次不执行A段烧录或任何通电项目。

## 实物前提

- 使用Pico 2（不是初代Pico），支持数据传输的Micro-USB线。
- 完整版首次接电脑前，GP7/8/9/10应分别有10kΩ上拉至3.3V；固件关闭内部上拉，未接外部上拉的裸板不能用于完整版按键验收。
- 矩阵R0～R4接GP2/3/4/5/6；C0～C3接GP7/8/9/10。每键为列→开关→二极管阳极→阴极色环→行。
- GDM0103：P3 DATA→GP0（物理1）、P2 /WR→GP1（物理2）、P1 /CS→GP11（物理15）、P5 VDD→3V3（物理36）、P4 VSS→GND（物理38）；明确3.3V版本，P6–P9分别绝缘不接。
- 先不合壳，方便核对线路。已有其他应用程序的板，烧录会替换原应用；BOOTSEL恢复入口仍在芯片ROM中。

## A. 后续烧录（本次暂不执行）

1. 在Replicator右键Product，选择Show in Finder，解压固件交付包。
2. 找到包内Pico 2 v0.2.0的UF2，勿把ZIP、ELF或BIN复制到BOOTSEL磁盘。
3. 断开Pico USB，按住板上BOOTSEL再接电脑；出现RP2350磁盘后松开。
4. 将UF2拖进RP2350磁盘；完成后磁盘会消失，设备重新启动。
5. 观察电脑是否出现CalcKey Dual Mode USB键盘，LCD是否先显示PC，随后PC 0或PC 1。出现BOOTSEL磁盘只代表进入烧录模式，不等于固件运行通过。

| 项目 | 预期 | 实际 |
| --- | --- | --- |
| A1 BOOTSEL | 出现RP2350磁盘 | 待测 |
| A2 复制UF2与启动 | 复制完成，磁盘消失 | 待测 |
| A3 USB枚举 | 识别CalcKey Dual Mode，保持连接 | 待测 |
| A4 LCD | 先PC提示，再PC 0/PC 1显示主机NumLock状态 | 待测 |

若无磁盘：先换已确认支持数据的线、直接接电脑USB口，再重试按住BOOTSEL上电。不要以板上LED亮灭判断烧录成功，当前固件没有设置运行指示灯。

## B. 电脑键盘

打开一份空白纯文本供测试，不在真实文稿中试Backspace。先确认普通数字输入正常；NumLock关闭时数字键可能表现为方向/导航，由操作系统决定。LCD显示主机返回的NumLock状态，该灯态是否返回也要按实际系统记录。

| R0C2 × | 数字小键盘乘号 * | 待测 |
| R0C3 Backspace | 删除刚输入的测试字符 | 待测 |
| R1C0/C1/C2 | 依次7、8、9 | 待测 |
| R1C3 − | 小键盘减号 | 待测 |
| R2C0/C1/C2 | 依次4、5、6 | 待测 |
| R2C3 + | 小键盘加号 | 待测 |

若整行/整列失败，先核对对应GP与焊点；若单键失败，核对该键、二极管方向和通断；若重复输入，先记录具体键与按住/轻触行为，不能直接判断为软件去抖问题。

## E. 切换、长按和连接稳定性

| 项目 | 步骤与预期 | 实际 |
| --- | --- | --- |
| E1 键盘→计算器时按住数字 | 在空白文本中按住7，再按Mode；电脑停止继续输入；仍按住的7不进入计算器，全部抬起后新按键才生效 | 待测 |
| E2 计算器→键盘时按住数字 | 按住7再按Mode；电脑不突然输入7；全部抬起后重新按7可输入 | 待测 |
| E3 主机长按 | 键盘模式长按数字，由电脑重复，抬起即停止 | 待测 |
| E4 超过6个主机键 | 7键同时按下不随机选键；全部松开后正常，不能残留卡键 | 待测 |
| E5 睡眠/恢复 | 睡眠时LCD熄屏，模式不来回跳；用电脑自己的键盘唤醒，全部抬键后CalcKey恢复 | 待测 |
| E6 重复插拔 | 多次接电脑/充电器，默认模式正确，无卡键 | 待测 |

| E8 运行稳定性 | 连续使用30分钟，记录死机、重启、屏幕异常及主机提示 | 待测 |
