# 佳达隆 KS-9 三脚红轴：小样采购与到货核对

日期：2026-11-05。用途：CalcKey 的20键手焊矩阵、14.2mm试配孔、打印MX十字键帽。本文是询价与小样验收说明，未向商家发消息、下单、付款或进行实物测试。

## 买什么、先买多少

- 采购识别型号：**GATERON / 佳达隆 KS-9 Red，KS-9H10B045NN-X14**，普通机械触点、全高MX十字轴芯、三脚版。三脚指两个金属电触点和一个中心塑料定位柱，不是三个电触点。
- 当前官方CAD文件身份：**KS-9H10B045NN-X14-FB**。整机依据该模型设计。厂家公开下载确有此标识，但未查到厂家对 **FB** 的定义或对去掉FB后完全等同的说明。
- 默认建议先买 **3颗、同批次、同完整料号**，编号S01/S02/S03。S01保留原样作基准，S02比较六孔及三种键帽，S03复核一致性并作备用；高温焊接或损伤后的件不再作原样基准。小样数量是本说明的建议，不把正式BOM中的20颗改成3颗，也不默认额外订购23颗。通过后凑足20颗合格可装机轴。
- 不接受未经核对的G Pro/Pro 2.0/Pro 3.0、Y35/Y51/D20后缀、静音版、五脚版、矮轴、磁轴或光轴代替。不能靠剪掉五脚版的塑料脚认定为同料号。只需要轴体，不需要键帽、轴座或LED。

## 到货要量哪些尺寸

统一基准A：轴体法兰真正压在面板上的**支承底面**，不是法兰上表面。自由位置指没有按键帽、没有手压轴芯；X/Y方向拍照标记，同一侧的卡扣、引脚朝向保持一致。配套记录表按S01–S03分别填写。

以下数字是当前官方STEP的测量参考，**不是厂家公差，也不是收货上下限**。厂家尺寸图的公差优先；没有公差时记录差值与量具误差，交回复核，不自行给出“±0.1mm合格”。卡尺显示0.01mm不代表准确度为0.01mm。

| 项目 | 当前模型参考 / mm | 量法和用途 |
| --- | --- | --- |
| A面→自由轴芯顶 | 10.200 | 最重要座高；用不压轴芯的方法量差高，勿误取法兰上面 |
| 最大外廓X / Y | 16.221 / 15.720 | 包括凸筋、卡扣和法兰的最大包络，不是14.2安装孔或单纯下壳宽；先标方向，避免卡尺压缩弹性卡扣 |
| 最低点→自由轴芯顶 | 18.600 | 含完整引脚的总高；弯脚会使测值失真，应同时拍照 |
| A面→最低点 | 8.400 | 含引脚，用于底部接线避让；不是下壳本体高度 |
| 十字总跨X / Y | 约4.000 / 4.000 | 模型在A面上方8mm截面的参考；不要只量顶端倒角，臂端和圆角外形也需近照 |
| 活动轴芯根部外廓X / Y | 5.000 / 6.550 | 能接近时轻量并拍照；模型参考，勿把它当十字孔尺寸 |
| A面→活动轴芯根部顶 | 6.600 | 影响键帽插座避让；难测时填写“未测”，不拆轴猜值 |
| 金属脚位置、中心柱、卡扣钩和允许板厚 | 待对应料号的厂家机械图/实测 | 表中不填未经测量的标准MX数值；底视与两向侧视需拍清 |

按压力、触发行程和总行程属于另外的功能参数：现有选型为线性45±15gf、预行程2.0±0.6mm、总行程4.0mm Max。总行程“Max”不是“4.0±某公差”；没有测力计时不能凭手感确认45gf合格。到货先观察是否线性顺畅、能完整回弹，再按厂家图与试配记录复核。

## 先试配，再决定是否补足20颗

1. 保留商品截图、订单备注、包装标签和卖家答复，给三颗贴S01/S02/S03编号。检查是否同版、有无弯脚、裂纹、拆卸痕迹和卡扣损伤。
2. 先记录未安装、未加热状态的尺寸。不夹压轴芯或卡扣来“量出”目标数值；难测项留空并说明。
3. 在六孔试片中先试当前主壳基准C（14.2mm孔、1.50mm台阶、16.4mm背面避空）。明显过紧即停，换较大孔作比较；不要为迁就模型硬压或打磨轴体。再按试片指南比较孔宽和1.35/1.65mm台阶，记录支承面是否坐平、卡扣是否回弹、晃动与拔取保持情况。
4. 在适合的孔内试**新版**P0/P5/P10键帽：十字孔长/臂宽4.10/1.40、4.15/1.45、4.20/1.50mm，深3.3mm。托住轴体沿轴线轻推，量松开/压到底的帽底间距，检查回弹、上盖摩擦和拔取裂纹。模型名义参考为5.5/1.5mm；不能据此强压到该高度。局部最薄壁0.20–0.25mm，漏线或开裂即停。
5. 可在未连接Pico、未供电时，以万用表检查两个金属电触点：松开开路、按下导通、释放恢复。勿把中心塑料柱当电触点；不需要烧录来做此检查。
6. 保存S01原样；S02/S03结果应分别记录。若样品间几何、卡扣或手感明显不一致，或任一关键项未闭合，不把一颗能插入当成整批通过。尺寸差异先复核量法、图纸版本与CAD，再决定补购或改设计。

进入正式装机的条件：完整料号/版本有足够可追溯依据，实际孔扣配合、键帽松紧、全行程回弹和断电触点检查可用，且采购批次与通过小样对应。仅靠型号文字、照片相似或CAD没有穿插均不够。
