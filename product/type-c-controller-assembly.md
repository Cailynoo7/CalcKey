# RP2350-Plus-16MB Type-C版装配与接线

主控：Waveshare RP2350-Plus-16MB，无排针，SKU 29761。使用原生USB-C，不接板载电池座，不额外焊USB信号测试点。固件为CalcKey v0.3.0，目标waveshare_rp2350_plus_16mb；旧Pico 2的v0.2.0保留为历史。

## 断电安装顺序

1. 拔USB，先完成矩阵PCB与LCD原有断电检查；新主控保持不供电。矩阵的R/D器件、黑环方向及J点网络没有变化。
2. 在底盖四个主控边缘座上各贴6×1.4×0.15mm绝缘胶片。按模型方向放入主控：Type-C向右、元件面向上。原厂STEP把PCB表现为0.41148mm厚的薄板，未给出实物板厚公差；实际座高、背面焊点及板边承托要复核，不能靠拧紧压桥强行弯板补差。
3. 先在主控下侧低位焊接矩阵10线与LCD5线，分别套好热缩绝缘。每根总长150mm，线皮外径不超过1.3mm；不要安装排针或杜邦插座。夹持区不得留锡珠或裸露焊点。
4. 两只PLA压桥的四个板边夹持面各贴一片6×1.4×0.15mm绝缘胶片，放入对应位置；4颗ISO4762 M2×6轻拧均匀固定。压桥只压板边，桥拱跨过芯片；螺钉不穿主控板，不用旧M2×4或随意加长。实物芯片、按键与焊线不得顶桥。
5. LCD仍按原边缘托架与0.15mm胶片安装，P6～P9各自绝缘不接。使用五处线束固定桥，矩阵跨壳线各保留至少65mm未粘死自由段；LCD线只固定到底盖，余线松放。电源跨板线从两压桥中间通过，信号沿板前缘分散出线；右矩阵余线区移至(26,-39,4.55)、20×16.8×3mm，旧宽扇出预算不再适用。
6. 主壳与底盖闭合前，核对底盖一体接口立台滑入主壳维护缺口；真正USB开口是9.44×3.66mm圆角长孔，不是立台外侧的维护接缝。检查Type-C插座对中、板不晃动、线皮不夹入接缝，再拧4颗M3×8合盖螺钉。开口由portcut按原厂插座正面8.94×3.16mm、R1.28每侧外扩0.25mm，中心较上版上移0.5mm；外唇厚0.7mm，内侧为较大金属壳避空；实际插头是否完全就位仍待断电试插。

## 15根导线

原厂针脚证据：https://www.waveshare.net/w/upload/c/ca/RP2350-Plus-details-inter.jpg ，原理图：https://files.waveshare.com/wiki/RP2350-Plus/RP2350_Plus.pdf 。端到端测量以焊盘文字和物理脚号为准，不凭线色。

| 来源 | 主控GPIO/电源 | 物理脚号 |
|---|---|---|
| J1～J5 | GP2、GP3、GP4、GP5、GP6 | 4、5、6、7、9 |
| J6～J9 | GP7、GP8、GP9、GP10 | 10、11、12、14 |
| J10 | 3V3 OUT | 36 |
| LCD P1 /CS | GP11 | 15 |
| LCD P2 /WR | GP1 | 2 |
| LCD P3 DATA | GP0 | 1 |
| LCD P4 VSS | GND | 38 |
| LCD P5 VDD | 3V3 OUT | 36 |

矩阵板没有GND端子；J10不接VBUS或5V。LCD必须是3.3V/6点钟版本。完整15线逐线表在同名CSV中，读数空白、状态待测，不覆盖以前的实物记录。

## 断电检查与维护

- 主控未连接时：J6～J9各到J10约10kΩ；矩阵逐键红笔接列、黑笔接行，松开OL、按下有正向二极管压降，反向OL。接入芯片后不再要求所有信号对之间均为OL。
- 每根线检查端到端导通和相邻脚锡桥；确认LCD 3V3/GND无反接、P6～P9不碰铜、板载电池座悬空；合盖前后比较电源对地读数，电容充电造成短暂蜂鸣需观察变化，不能只听蜂鸣下结论。
- 检查压桥不碰芯片或按键，不弯板，不夹焊点；Type-C断电试插、正反插及胶壳靠位均待实物验证，数字模型通过不代替插拔力与承载试验。
- 维护先拔USB，卸4颗底部M3，手托底盖沿壳体局部负Z缓慢下放30mm。接口立台、主控、压桥及翻脚都随底盖退出；不需要先横向硬撬Type-C口。8颗螺钉中只有4颗M3先卸下，4颗M2压桥螺钉随组件保留。完全分离仍需断开相应导线。

本说明仅用于制作准备；没有打印、上电、烧录或填写实测结果。当前完整制作包提供Type-C版30个打印件，四件从当前STEP转换、26件经几何与哈希核对复用；按production/model-manifest.json及package-manifest.json指定的版本取用。
