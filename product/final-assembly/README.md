# CalcKey Type-C整机装配与断电检查

采用RP2350-Plus-16MB无排针版（SKU 29761）、矩阵PCB和GDM0103 3.3V/6点钟LCD，固件v0.3.0。30个打印件、31项BOM和当前STEP由完整制作清单配套。本说明不启动打印、焊装、上电或烧录；全部154项实测保持空白/待测。

## 实物装配顺序

1. 拔掉USB、充电器和调试器；核对器件和30件打印件，先清理碎屑与支撑，后接近电子件。
2. 在独立矩阵板上焊4只10kΩ/0805和20只1N4148-TAP。二极管黑环K与方形pad1对齐，PCB底面视图中朝左；逐段检查电阻、二极管正反向和锡桥。
3. 轴体先扣入上面板，再从背面对齐PCB；确认坐平后焊40个金属触点。20个中心塑料柱孔不焊。按表逐键检查起始松开、按下、反向及释放，不能只听蜂鸣。
4. 15根线标两端：J1～J10到主控10线，LCD P1～P5到主控5线；每根默认150mm。主控焊端先做低位直焊与独立绝缘，再装两只压桥。J10和LCD P5到3V3 OUT/物理36，LCD P4到GND/38；矩阵没有GND端子。
5. 主控Type-C朝右，四个底盖座面和四个压桥接触面各贴6×1.4×0.15mm绝缘垫，共8片；压桥用4颗M2×6。螺钉不穿板、不压器件、不拧弯主控；实际板厚和背面焊点须检查。板载电池座保持不接。
6. LCD按边缘座及四片2×4×0.15mm绝缘胶片固定，P6～P9各自绝缘；保护片单独切割并用周边胶框安装，不压玻璃。翻脚、销轴及短帽按机构说明组装，胶只进入轴端盲帽。
7. 五处固定桥只夹线皮。矩阵跨壳每根至少65mm自由段；LCD五线只固定到底盖。右矩阵余线区20×16.8×3mm，压桥中间5×23×1.5mm区只供三根电源线，信号沿板前缘分散，不堆到夹持面或芯片上。详见Type-C主控装配及线束说明。
8. 检查电源节点、绝缘、夹线及20键回弹后自然合盖，再轻拧4颗M3×8。Type-C接口立台与底盖一同装入维护缺口；开口9.44×3.66mm，不靠螺钉拉合顶住的壳体。
9. 外部全断开时，用另一端悬空的USB-C线做正反向机械试插。维护卸4颗M3并手托底盖下放30mm，主控、LCD、压桥、翻脚随底盖退出；不横撬接口，不靠线束吊底盖。完全分离仍需脱焊矩阵线，可插拔接头尚未采用。
