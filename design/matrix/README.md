# CalcKey 20键矩阵PCB

主控采用Pico引脚兼容的RP2350-Plus-16MB，保留GDM0103，增加4列5行的被动矩阵PCB。本板不承载主控或LCD，不另设USB、稳压器或电池。沿用GP2～GP6行、GP7～GP10列，3V3为四个10k上拉供电；LCD五线仍直接焊至主控。PCB已完成布线与发布，Gerber、钻孔及三维机械交付均已生成。全部器件手工焊装；JLC贴片CSV为空。

默认73×96×1.6mm、双层FR4、1oz铜，顶面朝按键，底面为维修侧。板中心对应外壳局部(0,-14)，顶面z16、底面z14.4；20轴由原打印面板夹持，PCB通过20轴的焊脚连接固定，不新增壳体螺柱。轴体为已确认KS-9H10B045NN-X14，焊接式，不使用热插拔座。

器件默认：20个原型号1N4148-TAP轴向二极管在板背卧装；四个10k±1%、1/8W上拉改用0805W8F1002T5E（0805，可手焊）。J1～J10为PCB背面直接焊线的焊盘，分别为ROW0～ROW4、COL0～COL3、3V3，共10根26AWG柔性引线，沿底面平铺。LCD另用5根引线。无需GND连接到本被动矩阵板，也不铺无电气用途的地铜。

每键电路为COL→SW→二极管A→K→ROW；二极管黑环朝K，库封装pad1为K、pad2为A。矩阵PCB上的丝印与断电极性检查须以最终发布资料为准。旧版手焊行列指南及完整包保存的是此前手焊整机，不用于代替本板Gerber。

机械依据：沿用19.05mm键距和原20轴中心。KS-9原厂STEP测得安装面到板上方定位根部5mm，PCB上表面与该高度对应。原厂STEP中两电触点相对中心柱约(-5.06,+2.54)、(-2.5376,-3.8)mm，KiCad三脚Plate型封装转90°后为(-5.08,+2.54)、(-2.54,-3.81)mm，孔径1.5；中心柱孔径4mm。已对原厂CAD进行截面测量，最终仍需检查实际发布模型、钻孔及与外壳的间隙，不能仅据通用MX名称判定兼容。
