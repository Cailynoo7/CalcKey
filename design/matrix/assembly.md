# 矩阵PCB装配与断电检查

适用73×96×1.6mm矩阵板、20个已确认KS-9三脚红轴、RP2350-Plus-16MB与GDM0103。正面朝键帽，二极管、电阻和J1～J10焊线点在背面。本板不用排针、插座、热插拔座或新增USB接口。全部元件由操作者焊装；发布包的JLC贴片表为空，不能把它当作已安排贴片。

配套直观图见`product/matrix-assembly-diagrams/`：四页PDF及单页SVG/PNG，包含器件正反面、J1～J10到主控物理针脚、GDM0103正反面端子与五线，以及底面二极管/0805放大图；附接线CSV和空白断电检查记录。图对应当前PCB发布17123bc08553；旧手焊行列图不用于本PCB焊盘定位。

逐项操作使用同目录`guided-soldering.md`，包含分段焊接、20键松开/按下/反向/释放测试及异常排查。四个上拉与20键测试在主控/LCD电气分离时进行；接好芯片后不能沿用相同的在路阻值判据。全程不上电、不烧录。

## 元件与位置

- SW1～SW20按正面从远端到近端、每排从左到右编号；每排4键，共5排，中心距19.05mm。
- D1～D20对应同号按键，1N4148-TAP，DO-35；弯脚间距7.62mm，背面卧装。黑环K对准封装K线和方形pad1；pad2为A。不要把背面看到的左右方向当作正面方向。
- R1～R4为0805W8F1002T5E，10kΩ±1%、125mW；分别上拉COL0～COL3。它们是0805贴片电阻，替代旧手焊版的通用轴向电阻。
- J1～J10为板上一体焊线铜垫，连接10根26AWG、每根150mm的绝缘软线。剥线只够覆盖铜垫，平铺向内，焊点不能承担开盖拉力。用已有聚酰亚胺胶带固定线皮，不在此处装直立排针。

## 主控接线

| 矩阵板焊点 | 信号 | RP2350-Plus-16MB |
| --- | --- | --- |
| J1 | ROW0 | GP2 |
| J2 | ROW1 | GP3 |
| J3 | ROW2 | GP4 |
| J4 | ROW3 | GP5 |
| J5 | ROW4 | GP6 |
| J6 | COL0 | GP7 |
| J7 | COL1 | GP8 |
| J8 | COL2 | GP9 |
| J9 | COL3 | GP10 |
| J10 | V3V3 | 3V3输出 |

矩阵板没有GND端子；行是扫描GPIO，不能接GND。J10不能接5V、VBUS或VSYS。本板只由四个上拉电阻从3.3V取电，四列同时拉低的名义总电流约1.32mA。

LCD仍独立直焊：P1 /CS→GP11、P2 /WR→GP1、P3 DATA→GP0、P4 VSS→GND、P5 VDD→3V3；P6～P9分别绝缘不接。LCD低位引线不通过矩阵板。GPIO依据沿用整机接线记录中的微雪官方引脚图：https://www.waveshare.net/w/upload/c/ca/RP2350-Plus-details-inter.jpg ；LCD端子依据：https://www.radiomag.com.de/datasheets/gdm0103_specification.pdf 第8页。

## 装配顺序

1. 全程断开USB；先检查裸板板框、孔和焊盘。先焊四个0805上拉及20个二极管，检查黑环、锡桥和虚焊；二极管引脚从正面剪短，避免超出发布模型预留的低位空间。
2. 取下打印键帽。将20个轴从主壳正面扣入打印面板，确认每轴坐平；PCB从下方对齐中心柱和两个触点，不能横向强压弯脚。原面板承担轴体安装，PCB通过20个轴的焊脚连接固定，不另加螺柱。
3. 保持轴体坐平且PCB无翘曲，再从背面焊接40个轴触点。烙铁不能碰打印壳体；按所用焊料和元件的工艺要求操作。先不安装键帽，检查每个轴回弹。
4. 按表焊接J1～J10至主控，保留150mm维护余量；LCD按其独立表焊接。交叉处保留完整绝缘，余线沿底盖平铺，固定线皮，避开USB插头、合盖柱和翻脚机构。
5. 完成断电检查后再合盖。主控通过两只压桥固定，LCD位于底盖托架，矩阵与主壳留在一起；维护时托住底盖，卸4颗M3后缓慢下放30mm。完全分离仍需要断开焊线，不拉PCB铜垫。

## 断电检查

1. 目视核对4个电阻均为10k、20个D黑环与K标记一致，所有引脚处无锡桥或裸线碰壳。
2. 在未连接主控/LCD时测四列至J10：每列约10kΩ；两列之间可经两个上拉读到约20kΩ，不应误判为短路。按键全部释放时，行列不应直接低阻连通。
3. 逐键按下，以二极管档红表笔接该列、黑表笔接该行，应出现正向压降；交换表笔应截止。共20键逐项记录；在路路径可能影响读数，异常时分离对应元件检查。
4. 按表核对每根引线的端到端通断、相邻裸焊点无短路；LCD未使用端子各自绝缘。最后核对J10只接3V3，行不是GND，屏幕电源是3.3V。

本任务没有替操作者填写实测通过，没有下单、打印、烧录或供电。当前v0.3.0的行列GPIO、二极管方向及四列外部上拉拓扑保持；上电功能仍待后续验收。
