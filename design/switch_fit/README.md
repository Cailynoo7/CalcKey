## 制作和装配

仅准备本小试片及既有三帽，不打印整机。本试片默认与PLA主壳一致：0.4mm喷嘴、0.15mm层高（首层默认也0.15mm）、4道外壁、100%填充、100%比例。带刻字的装轴正面朝下贴板，背面16.4避空朝上；复现主壳键面朝下的加工方向，不向轴孔和夹持台阶内加支撑。切片中保留A–F方孔，检查孔口象脚、线宽、薄台阶层数及文字空域；打印机/材料/补偿参数均记录，不能用不同补偿制造“通过”。

1. 冷却后清除毛刺并测实际孔宽X/Y、总厚及台阶；不先强行扩孔、削卡扣或涂胶。若有象脚，记录后只去可见毛刺，再量尺寸。
2. 轴未接线、无电源。先用裸轴从较松的D孔尝试，再C/B/A；明显过紧或卡扣不能回弹即停止。按压外壳肩面、对正卡扣方向，不通过压轴芯把轴体硬顶入。检查肩面坐平、各卡扣在背面释放、侧向晃动与轻微拔出保持。
3. E/F只比较14.2孔下的1.35/1.65台阶；不能拿不同孔宽与台阶同时变化推断单一原因。移除轴时先从背面释放各原轴卡扣，再沿轴线退出，避免拔取损坏试片。
4. 选择坐平、卡扣回弹并有保持力的孔，托住实物轴体，依次试P0/P5/P10；键帽PETG按既有工艺单独制作（0.2mm喷嘴、0.1mm层高，平顶朝下）。不要求两种材料/喷嘴混在一次打印里。
5. 记录帽底到安装正面的静止/按到底间距、名义4mm全行程回弹、帽裙/插座是否碰轴体上盖或试片，以及拔帽/插座裂纹。先校孔和台阶，再校帽孔；不以拔帽拉力破坏卡扣代替保持检查。
6. 装入轴后其底座、塑料柱和金属触点会伸出背面。手持外缘或在两端架起，背面留至少12mm临时净空；不要把轴脚压在桌面上测试，12mm是试验工装默认而非厂家底部尺寸。
7. 实测填六孔记录及六孔×三帽配对记录；只需完成所选合理孔与三帽的组合，不合适的孔标记不适用及原因。选定孔宽/台阶/帽孔与实际高度后再修改正式主壳和20帽；本次不先改正式尺寸。

1.35–1.65mm薄台阶为仿照真实夹持接口的试验特征；最薄环带宽约1.05mm，不适用外壳整体2mm壁厚规则。不得把试片当成高强度结构。文字为浅凹刻，不是分离字块。无螺钉、无新增打印弹片，使用原轴卡扣。

## 检查与边界

本件检查目标为一个有效连续实体、六孔/下侧避空与T台阶尺寸、C与当前主壳接口一致、刻字不穿板，以及按暂定帽底离面5mm/行程4mm时的外廓空间。CAD不能确认精确轴体的肩位、卡扣压缩与回弹、保持力、键帽松紧/裂纹或打印收缩。KS-9官方STEP已导入整机，试片不含模型；卡扣弹性与保持力仍需实测，实际打印与测量全部待测；不烧录、不通电、不开始整套外壳打印。

接口key_fit、keycap_stem_fit；真实轴体身份与装配结果见KS-9装配核对，三帽尺寸及工艺见keycap_fit说明。历史MX系列1.5mm名义接口只作背景；本件变量是自主试配值，不宣称为佳达隆原厂公差。
