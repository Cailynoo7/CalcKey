# CalcKey 打印键帽孔隙试配

三只完整1U平顶PETG键帽，P0/P5/P10，分别为十字孔长/臂宽4.10/1.40、4.15/1.45、4.20/1.50mm。孔隙增量是总尺寸增加量，不是每侧间隙。名义帽体18.2×18.2×7mm，顶宽14.4、壁1.2、顶厚1.6、插座上段外径5.6，下段两侧削平宽4.8至z5.1、入口内缩1.4、盲孔深3.3、导向0.1mm。每只帽壳、插座融合为一个有效实体，顶面凹刻编号。

## 制作和装配

默认PETG、0.2mm喷嘴、0.1mm层高。平顶朝下、帽腔/孔向上；插座小截面用连续周长填实，检查切片不漏线、不封孔，孔内不生成支撑。三样保持同一工艺。最薄入口端壁P0/P5/P10分别0.25/0.225/0.20mm，属于小插座的工艺试样，需要实际打印确认，不能按外壳壁厚判断其强度。

支撑实物GATERON KS-9H10B045NN-X14，沿轴线轻推，记录松紧、就位高度、拔取与反复插拔后裂纹；确认4mm行程和回弹不蹭轴体上盖/面板。三样都不合适时重新调整配合增量。禁止用过度硬压或涂胶掩盖不合适。试样与20帽采用相同结构，选择结果再写回正式键帽公共配合参数。官方模型轴顶距支承底面10.2mm，止挡4.7，帽底名义离面5.5mm；实际仍需量测。

## 检查与边界

已查看底面与顶部，三只各为一个有效实体；只读截面确认孔长为4.10/4.15/4.20mm、臂宽1.40/1.45/1.50mm，深度均3.3mm。没有导入近似轴体，三种试样仍须在实际KS-9上确认松紧、内部避让和薄壁强度，尚未打印或实测。此设计在共享场景中移到X=125mm，与整机分开；不改整机外壳。

接口keycap_stem_fit。参考Adafruit https://learn.adafruit.com/3dprinted-custom-keycaps/customize 和KeyV2作者参数 https://github.com/rsheldiii/KeyV2/blob/master/src/settings.scad 。本项目结构自行建模，孔隙为试配默认，未照搬厂家公差。
