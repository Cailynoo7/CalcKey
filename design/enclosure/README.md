# CalcKey：Type-C数字键盘与八位计算器

## 产品与造型
用户指定Waveshare RP2350-Plus-16MB无排针版，SKU 29761，替代原版Pico 2；不额外增加USB转接小板。主控不在平台索引中，使用用户授权的库外器件及原厂RP2350-Plus系列STEP。板载电池口保持悬空，不配电池，不使用其充电功能。电脑USB枚举后为HID数字键盘，只接5V USB电源时为本机计算器。
造型保持89×130×21mm紧凑顶侧一体主壳、独立底盖、两档翻折角柱脚；主壳、底盖和主控压桥为浅薄荷绿sRGB #C4E4DA，键帽配色保持。前侧CALC浅刻、上缘0.4mm倒角和各键布局均保持。屏幕为GDM0103/HT1621B，3.3V、6点钟视角，初版不接背光；64×16mm窗口、67.6×19.6×1mm保护片、底槽68×20mm，胶框厚0.15mm。

## 制作和装配
正式打印件30件：PLA主壳、底盖、两只主控压桥；PETG两只翻脚、两根销轴、两只端帽和20只键帽。Pico历史件不再装机，Waveshare主控、矩阵及轴体、LCD、螺钉和亚克力片不打印。
壳体默认0.4mm喷嘴、0.15mm层高、4壁、20%填充；压桥建议100%填充，沉孔向上，板边压脚向下，局部支撑只托桥底非接触区，清理后贴绝缘胶片。底盖外侧朝下、座面和接口立台朝上，轴耳/限位局部支撑；Type-C胶囊顶弧可桥接或用可移除局部支撑，不在狭小插口内留下难以清理的支撑。主壳键面朝下、底部开口朝上，内伸线束桥需局部支撑，避开卡扣、螺纹孔及穿带口。键帽0.2mm喷嘴、0.1mm层高、顶面朝下，帽腔向上、孔内不放支撑。整机倾斜姿态不是打印朝向。
合盖4颗ISO7380-1 M3×8；主控压桥4颗M2×6，8处接头来自printed-screw-joint-v1，沉孔头低于桥面0.2mm。打印自成形孔只轻拧，实际扭矩和寿命未测。先粘绝缘垫、低位直焊主控15线，再安装压桥，焊后线皮和焊点不得被夹。LCD/保护片沿用边缘座及薄胶方案，先做断电逐线检查再合盖。
后脚中心距59mm、宽10、长8.5、厚3.6，轴孔2.8、销轴2.4×17.8，挡头D5×1.5、盲帽D5×2.4、盲孔D2.6×1.2，轴端入帽1mm。双组份环氧仅用于轴端与帽内孔，不粘轴耳/转动面；胶材须按厂家说明固化。两档倾角约2.411°/4°，110°实体限位，展开略后倾；卸载不自锁。前垫D12×2，两档脚底仍贴世界Z=0，支脚与键帽几何未改；承载和反复翻折无实测。
