# CalcKey：宽屏八位LCD数字键盘与计算器

## 产品与硬件

电脑USB连接时作为HID数字键盘，只接5V USB充电器时作为本机计算器；拔USB即关机，无电池、仓盖、电池开关或充电电路。Raspberry Pi Pico 2、20个GATERON KS-9H10B045NN-X14、自制等高1U PETG键帽、5行4列手焊矩阵，无定制PCB。显示改为Good Display / 大连佳显GDM0103，HT1621B八位段码TN LCD，明确订购3.3V、6点钟视角，初版不接背光。模块78×26×10mm最大，可视区60.5×13.5、数字图形57.15×10.70mm。不是六位HT1621模块，也不是未带驱动的GDC裸玻璃。

用户要求显示接近原窗口两倍宽，允许调整长宽；本次窗口从32×16改为64×16mm，保留较短纵深，机身仍89×130×21mm。显示中心局部(0,49)，到首排18.2mm打印键帽边缘7.30mm。主壳顶侧一体、独立底盖维护；上缘0.4mm倒角，前侧0.35mm浅刻CALC及四条短斜线。

两只翻折角柱脚保留：收起约2.41102975°、展开4°，行程0～110°，展开后向世界竖直后方倾24°。两档实体限位承载，卸载不自锁。展示及STEP是展开姿态：整机X=4°、Z平移6.459542420mm；后脚绕局部支点额外110°。收起姿态整机X=2.41102975°、Z=4.690580828mm，后脚0°；桌面世界Z=0。

## 接线与固件接口

| 信号 | Pico GPIO / 物理针号 | GDM0103端子 |
| --- | --- | --- |
| DATA | GP0 / 1 | P3 DATA |
| 写时钟 | GP1 / 2 | P2 /WR |
| 片选 | GP11 / 15 | P1 /CS |
| 电源 | 3V3 / 36 | P5 VDD |
| 地 | GND / 38 | P4 VSS |
| 未使用 | 不接，逐个绝缘 | P6 /INT、P7 BL+、P8 BL-、P9 Ctrl |
| R0–R4 | GP2/4、GP3/5、GP4/6、GP5/7、GP6/9 | 各行4只二极管阴极 |
| C0–C3 | GP7/10、GP8/11、GP9/12、GP10/14 | 每列5开关一端；10k上拉至3V3 |
| USB | 原生Micro-B | 电脑或5V USB充电器，择一 |

LCD按手册第8页端子名接线；三线GPIO位操作写入，不能沿用I²C。3.3V版本无5V逻辑输入。P1–P5短软线直接焊，板背焊点/首段导线突出≤1.5mm；无直立排针，连接朝板内折，不能顶玻璃或挤边缘座面。另留150mm维护余量，独立固定线束不靠焊点承力。背光端本版不接；后续背光若启用，应先核对该变体电流及限流，不直接接GPIO。

每键接法：列→开关→1N4148阳极→阴极色环→行。选中行输出低，其余高阻，列外部10k上拉，低为按下；目标5ms去抖、至少500Hz扫描。开关/电阻1、2是项目端子名，无源触点不假定极性。USB枚举成功才默认键盘；仅充电器为计算器；Mode允许本地计算，切换释放所有HID键，主机挂起不反复切换。

接线图已更新为GDM0103 LCD-B四页A3版本，断电焊接手册为九页A4版本，附五张实测表；正反面、五根LCD线、四个NC端及14个Pico针脚均已核对；旧v0.1.0固件为SSD1315版本，不适用于本屏。LCD驱动已在v0.2.0实现并通过桌面测试及Pico 2交叉编译。8字符显示默认非负8位、负号占一位、小数点独立段；模式切换短暂PC/CALC、错误Err，不常驻完整运算符。固件交付及验证结果见独立固件说明，实机验收仍待后续；按用户要求未烧录/通电。

## 制作和装配

主壳/底盖PLA，后脚/销轴/盲帽PETG。默认0.4mm喷嘴、0.15mm层高、4道壁；壳体20%填充，销轴与帽100%。可选石墨壳体、青色后脚，各件单色。底盖外侧朝下、托架朝上，外侧轴耳/限位需要底板下支撑；铰链孔桥接并清理，避免支撑挤孔或限位面。主壳键面朝下、底部开口朝上，USB约13mm桥接必要时局部支撑，避免轴孔/卡扣/螺纹孔内支撑。后脚X端贴床，销轴挡头贴床且轴线竖直，帽闭口端贴床、盲孔朝上。整机STEP姿态不是各件打印姿态。保护片切割，键帽另按细喷嘴工艺。

直接制作正式件；装配时检查KS-9是否坐平、全行程回弹及焊脚绝缘，不把未做的打印验证记录为通过。核对实物LCD确为78×26板框、3.3V、6点钟视角及P1方向，量板厚、背面凸起和显示中心；干装检查玻璃到保护片、周边不受挤压。托架只接PCB边缘；确认四处粘接带无铜/元件，清洁后贴0.15mm绝缘胶片并轻压PCB就位，不压玻璃。若原模块有直立排针，拆除并改低位直焊；焊点及首段导线朝内，板背突出≤1.5mm。LCD无背光也可在有环境光条件下使用，P6-P9分别绝缘。

把Pico两孔固定到底盖，LCD粘到托架；主壳贴0.15mm胶框和保护片。装轴、焊矩阵/逐键二极管并绝缘，按当前LCD接线表接Pico。线束维护余量150mm，余线贴底整理，避开器件/卡扣/USB/合盖柱。底盖对准定位唇，从下方合入，拧4颗M3，前端贴D12×2硅胶垫。

后脚放进轴耳，穿17.8mm短轴，干装盲帽检查0～110°和双端限位。勿混用旧长轴。先做所购环氧胶与实际PETG小样，只胶轴端/帽内孔，避免溢胶，按胶材说明固化。两脚在同档限位后落桌，验脚底贴合、摇晃、受压回折、滑移、销轴与帽脱出；未实物承载/反复翻折前不视为结构验收。

维护先拔USB、抬起/翻转设备，卸4颗底部螺钉，底盖携Pico、LCD和翻脚沿局部负Z缓慢下放30mm；手托底盖，不靠线承重。完全分离需断开相应焊线。LCD去胶时支撑PCB，勿撬玻璃或斑马条。LCD固件v0.2.0已完成编译，后续再分别验电脑/充电器双模式；本次先不烧录。

## 自制打印键帽

20个键帽已从外形参考改为实际打印件，每个键帽一个独立零件。keycaps同时提供公共帽体参数并发布Num帽；其余keycap_02至keycap_20读取同一帽体与插座，仅分别凹刻键位文字。key_01至key_20都包含帽壳、圆柱插座和十字盲孔，没有独立悬浮的字符或未连接底座。

默认帽底18.2×18.2、顶宽14.4、高7mm；壁1.2、顶1.6、凹刻0.35mm。插座外径5.6，下段两侧削平至4.9mm宽，到帽内z5.1结束；十字孔长4.10、臂宽1.40、深3.3，入口内缩1.4、入口不扩口，止挡距帽底4.7mm。插座与顶壁融合，20帽均一个有效实体。削平段入口局部最薄壁约0.40mm，是细喷嘴FDM的局部特征；用户选择跳过试配并直接制作，实际强度未测。

KS-9官方STEP文件标识KS-9H10B045NN-X14-FB，20轴以不可缩放的原厂资产实例装入。原模型法兰支承底面z16.2，上表面z17.2，自由轴顶z26.4；支承底面到轴顶10.2mm。键帽对齐轴芯相对中心柱的偏心(+0.05,-0.000674)mm，帽底距面板5.5mm，名义压到底余1.5mm。主壳89×130×21mm、19.05mm键距、14.2孔/1.5台阶/16.4下避空保持。

20个轴体对面板仅存在两处小侧向定位筋的名义干涉：每轴0.15936mm³，报告深度0.1374mm，已记录为0.16mm预算的compliant试配。未把法兰埋进面板；卡扣回弹、保持力及弹性是否足够仍须实际试配。
